# Roadmap

1. Bootstrap and canon: contracts, schemas, project skeleton, asset audit.
2. Vertical slice: character creation, one route, recruit, quest, dungeon, boss, save/load.
3. Core engine: party, jobs, equipment, status/element systems, factions, schedules, content packs.
4. Campaign: three regions and a complete authored 20+ hour route.
5. Living world: owner-hosted generation, validation, caching, persistence, fallback.
6. Release hardening: accessibility, rebinding, performance, migration, license/IP audit, full playthrough.

A milestone is complete only when its loop is playable, relevant automated tests pass, and save compatibility is verified.
